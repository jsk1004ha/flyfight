FlyFight Native 0.2

Python 백엔드가 여러 경기의 물리·RGB 관측·두 독립 정책의 recurrent PPO 학습을 처리합니다. 브라우저는 학습하지 않고 신경 활성과 3D 장면을 표시합니다. 서버에서 연 페이지는 자동 연결됩니다.

관전은 학습과 분리

관전 경기는 CPU에서 별도로 실행하는 실제 정책 경기입니다. 학습 경기 하나를 느리게 재생하는 것이 아니며, 관전 경험은 학습에 넣지 않습니다. 새 가중치는 라운드 경계에서 반영합니다. 화면 일시정지·배속·창 닫기는 학습 속도를 제한하지 않습니다. ‘학습 일시정지’만 학습 워커를 멈춥니다. 배속 버튼 또는 B 키로 1×/4×를 전환하고 선택 상자에서 0.5×~8×를 고를 수 있습니다.

세밀한 조작과 헤드샷

네이티브 정책의 회전·상하 시점은 −1부터 +1까지 선택하며 --action-precision 2/3 설정으로 0.01/0.001 간격을 지원합니다. --turn-speed와 --pitch-speed로 초당 회전 속도를 지정합니다. 머리와 몸통 판정은 분리되어 있으며 헤드샷은 100 피해, 몸통은 34 피해입니다. 네이티브 새 학습의 기본 헤드샷 보너스는 +0.25이며 상대에게 −0.25가 적용됩니다. 처치 보상과 합하면 +1.25 / −1.25입니다. --headshot-bonus로 조절하며 기존 체크포인트는 저장된 조건을 따릅니다.

실제 입력 확인

‘시야: 실제 입력’은 백엔드의 저해상도 RGB raycaster 결과입니다. 엄폐물·벽과 상대의 구형 판정체를 그립니다. 상세 3D 초파리 모델과 픽셀 단위로 동일하지 않습니다. 화면의 입력 시각은 물리 상태보다 한 제어 스텝 앞선 관측 시각이며, 그 관측에서 계산한 활성과 행동을 함께 표시합니다. 밝기는 |RNN hidden state|, 좌표는 모식 배치, 연결선은 실제 dense 재귀 연결 중 일부입니다.

변하지 않는 학습 조건

자기 RGB 영상과 직전 행동만 입력합니다. 상대 좌표·전술·인간 시범·조준 보상은 주지 않습니다. 승패 기본 보상은 +1 / −1 / 무승부 0이며 헤드샷 차이에 대한 보너스를 더합니다. 정책·가치망 모두 같은 로컬 입력을 사용합니다. 탐색을 위한 entropy 정규화는 별도 학습 항입니다.

정확한 범위

현재 모델은 합성 RNN이며 FlyWire/BANC 커넥톰이 아닙니다. 학습 속도 개선 구조를 구현했지만 GPU 가속 배수와 실력 향상은 측정 전입니다. 3D 형상과 물리 판정은 단순화되어 있습니다. 단독 HTML의 ‘연출 모드’는 기존 규칙 기반 봇이고 ‘브라우저 실험’은 구버전 출력층 학습입니다.

64×48 게임 단위, 엄폐물 16개와 외곽벽 4개. 결투 추적 / 전체 맵 / A·B 추적 / 탑뷰. 드래그 회전, 휠 확대.

외부 신경 시뮬레이터 연결

run.py가 제공한 로컬 페이지를 열면 자동 연결됩니다. 위치·행동·신경 활성을 받고 허용된 일시정지·저장 명령만 보냅니다. 외부 데이터의 출처는 제공자가 선언한 정보이며, 이 뷰어가 진위를 검증하지는 않습니다. 연결을 끊으면 연출 모드로 돌아갑니다.
